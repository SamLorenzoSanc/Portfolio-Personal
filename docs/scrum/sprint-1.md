# Sprint 1: Autenticación y Gestión de Entregas (Backend)

**Objetivo del Sprint:** Implementar el sistema de acceso privado para el administrador y la API REST
para consultar, filtrar y eliminar proyectos, informes, ejercicios y planes de estudio.

## Sprint Backlog
- **US-01 (Seguridad):** Como administrador, quiero iniciar sesión con JWT para proteger las rutas de creación, edición y borrado.
- **US-02 (Modelado):** Como sistema, necesito almacenar 4 tipos distintos de entregas académicas bajo una colección unificada en MongoDB.
- **US-03 (Gestión):** Como administrador, quiero subir informes en PDF y registrar proyectos, ejercicios y planes de estudio mediante endpoints REST.
- **US-04 (Consulta):** Como visitante, quiero obtener el listado de trabajos filtrados por etapa académica, tipo o etiqueta sin necesidad de iniciar sesión.
